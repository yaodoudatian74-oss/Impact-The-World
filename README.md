# Impact-The-World 幻想ワールド

砕けた「星の核」を取り戻すため、6つの世界を旅するオープンワールド3DアクションRPG。
ブラウザだけで動きます（PC・スマホ対応）。

## 遊び方

- `index.html` を Web サーバー経由で開く（例: `npm run serve` → http://localhost:8080 ）。GitHub Pages でもそのまま動きます。
- `npm run build` で `dist/game.html`（1ファイルにまとめた版）を作れます。

### 6つの世界（それぞれ約8km四方）

| 世界 | 特徴 | 推奨Lv |
| --- | --- | --- |
| エメラルド平原 | 草原・湖・川・森・古代遺跡・風車の村 | 1〜15 |
| ヴォルカニア火山 | 溶岩の川と大火口。溶岩に触れると大ダメージ | 15〜30 |
| フロストピーク | 雪山と凍った湖。吹雪の中の氷の塔 | 30〜45 |
| アトランティア海底 | 自由に泳げる海の底。珊瑚の森と沈没船 | 45〜60 |
| セレスティア天界 | 雲海に浮かぶ島々。上昇気流と滑空で渡る | 60〜75 |
| コスモス宇宙 | 重力の弱い月面。巨大な惑星が浮かぶ空 | 75〜90 |

最初は平原だけ。各世界の第1章をクリアすると次の世界が解放されます。

### 仲間と専用武器

- 最初から5人（アレン・リナ・ミオ・ガルド・シズク）が仲間です。
- 各世界に物語が2章ずつ、全12章。**1章クリアごとに新しい仲間が1人、その子の専用武器と一緒に加わります**（全17人）。
- パーティは最大4人。「編成」で入れ替えられます。

### 操作

| PC | スマホ | 動作 |
| --- | --- | --- |
| WASD | 左側ドラッグ | 移動（Shift長押し / スティックを倒しきるとダッシュ） |
| マウス / ドラッグ | 右側ドラッグ | 視点（クリックでマウス固定、Escで解除） |
| 左クリック | 攻撃 | 通常攻撃（長押しで連続） |
| E / Q | E / Q | 元素スキル / 元素爆発 |
| Space | 跳 | ジャンプ、空中でもう一度で滑空、水中で浮上 |
| Shift | 駆 | ダッシュ回避 |
| Ctrl / X | 潜 | 水中で潜る |
| R | 騎 | 精霊の馬に乗る |
| F | ボタン | 話す・宝箱・ワープポイント・次元の門 |
| 1〜4 | 顔アイコン | キャラ交代 |
| H | 薬 | 回復薬 |
| M / C / J / Esc | 上部ボタン | 地図 / 編成 / 物語 / 設定 |

元素反応（融解・蒸発・過負荷・感電・超電導・凍結・拡散・結晶・輝光・侵蝕・対消滅）で大ダメージを狙えます。
宝箱、星のかけら（スタミナ上限アップ）、ワープポイントが世界中に散らばっています。

## 開発

```
npm install
npm test            # ルール・セーブ・ストーリーデータ・地形の単体テスト
npm run build       # dist/game.html を生成
npm run smoke       # ヘッドレスChromiumで起動・操作・全世界・メニューを確認
node tools/playthrough.mjs   # 全12章を実際のクエスト処理で通しプレイ
```

構成:

- `src/data/` キャラ・武器・敵・世界・物語のデータ
- `src/world/` 地形生成（`terrain.js`）、チャンク読み込みと描画（`world.js`）、モデル（`models.js`, `props.js`）
- `src/game/` ルール計算（`rules.js`）、戦闘、プレイヤー、敵AI、クエスト、セーブ
- `src/ui/` HUD・メニュー・会話・タッチ操作

three.js は CDN（jsDelivr, r170）から読み込みます。
